# Personal Website & Projects

This is my personal website showcasing **three different projects**, each highlighting different skills and technologies.

## Projects

### Small World Theory

A project exploring **math and probability**, demonstrating how closely we are connected.  
**Focus:** Data visualization, probability, interaction.

### 3D Tote Bag

A **3D model showcase** created using the **Three.js** library.  
**Focus:** 3D rendering, animation, and building interactive web experiences.

### Nicki Game

A **browser-based video game** developed with the **Phaser** framework.  
**Focus:** Game mechanics, sprite animation, and interactivity.

I hope this website will let you **know me better** and also **have fun** while exploring each project!

**Live website:** [https://my-cv-five-iota.vercel.app/](https://my-cv-five-iota.vercel.app/?fbclid=IwZXh0bgNhZW0CMTEAAR5R_u--B9gQPJkv8Y4yrVF5W4AKypcFASjBCHuuHfXum0BhhXaIMb76url2vQ_aem_LqdqminvaZn7Iw__IaRWQQ)

## Technologies Used

- **Framework:** Next.js
- **3D Library:** Three.js
- **3D Model:** Blender
- **Game Engine:** Phaser
- **Game design:** Adobe Illustrator
- **Styling:** CSS / Tailwind CSS
- **Hosting:** Vercel
- **Database** Supabase

## Usage

This project was bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

To run the development server locally:

```bash
npm install
npm run dev
```
